# Sanepar - site informativo

Projeto Next.js pronto para deploy na Vercel.

## Páginas

- `/sanepar`
- `/sanepar-segunda-via`
- `/sanepar-fatura`

## Antes do deploy

Substitua `https://SEU-DOMINIO.com` em `app/layout.js` e `app/sitemap.js` pelo domínio real.

## Rodar localmente

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy

Envie o projeto para um repositório Git e importe o repositório na Vercel.

O site é informativo e independente. Os links externos apontam para páginas oficiais da Sanepar.
